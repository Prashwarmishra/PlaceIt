Privacy Policy | InPlace

Effective Date: October 26, 2025

Last Updated: October 26, 2025

InPlace (“we”, “our”, or “us”) is a Chrome extension that helps users visualize products in their own space. We are committed to protecting your privacy and being transparent about how the extension works.

1. Information We Access

InPlace does not collect, sell, or share personal information. However, to function properly, the extension requires limited, user-initiated access to certain browser data:

  • Page Content (Active Tab): When the user clicks the extension icon, InPlace temporarily reads the content of the current product page to detect and extract product images. This happens locally and is not stored or transmitted to our servers.
  • Gemini API Key (Local Storage): If provided, the user’s Gemini API key is securely stored using Chrome’s chrome.storage.local API. It never leaves the user’s device except when making direct requests to the Gemini API. We do not collect or log this key.
  • External API Communication (Gemini): To generate visualizations, the extension sends the user’s background image and the selected product image directly from the browser to the Gemini API provided by Google. No data is routed through InPlace servers.

2. How We Use This Information

Data accessed by the extension is used solely to:

  • Read product page images after explicit user action
  • Combine them with user-provided background images
  • Generate AI-powered visualizations through the Gemini API

No information is used for analytics, advertising, or profiling.

3. Data Storage & Security

  • All API keys are stored locally using Chrome’s extension storage.
  • No personal or browsing data is stored remotely.
  • We do not use analytics or tracking tools.
  • Users can clear data at any time by removing the API key or uninstalling the extension.

4. What We Do Not Do

  • ❌ We do not collect personal data.
  • ❌ We do not store browsing history.
  • ❌ We do not track users or inject ads.
  • ❌ We do not share or sell data to third parties.

5. User Control

  • Users can remove their API key at any time from the extension’s settings.
  • All local data is deleted when the extension is uninstalled.
  • No data persists outside the user’s device.

6. Third-Party Services

InPlace communicates directly with the Gemini API, provided by Google. We encourage users to review Google’s Privacy Policy for more details on how that service processes data.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected with a new “Last Updated” date. Users are encouraged to review this page periodically.
